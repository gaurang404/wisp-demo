# Wisp Coffee API (demo)

A fictional coffee roaster's API used in [Wisp](https://github.com/gaurang404/wisp)'s screenshots and for trying Wisp out.

- **Docs:** https://gaurang404.github.io/wisp-demo/ — paste this into Wisp's *Import* to load every endpoint.
- **Spec:** [`openapi.yaml`](openapi.yaml)
- **Base URL:** `https://gaurang404.github.io/wisp-demo/api/v1`

Responses are static JSON on GitHub Pages: every request returns the same sample data, any `X-Api-Key` is accepted, and `POST` returns `405`. All names and emails are fictional.
